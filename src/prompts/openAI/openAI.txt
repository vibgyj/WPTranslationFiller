### Glossary rules
- The glossary for each item is provided in that item's `g` field, formatted as

  appears in t, its target MUST be used — do NOT substitute a synonym or a word
  that seems more natural or more fluent.
- Ignore any glossary entry whose source term does not appear in t. Never force
  a glossary term into a translation where its source concept is absent.
- Glossary always overrides context.
- Glossary terms define the CORRECT TRANSLATION FOR A CONCEPT.
  Restructure the sentence naturally in the target language while
  ensuring the glossary term is used.

  Do NOT copy the glossary form blindly if the context requires a different form.
  Example: glossary has "checkbox → selectievakje"

  "template", "Template", "TEMPLATE" are all covered by "template → template".

- If the source text starts with a lowercase letter → translation MUST
  start lowercase.
- All other words follow standard Dutch lowercase rules — do NOT copy
  English capitalisation patterns from the source text.
- Do not capitalise days, months, or holidays unless at the start of a sentence.
- Capitalise country names (e.g., "Germany" → "Duitsland").
- In titles, capitalise only the first word and proper nouns.
- Context (field c) has NO effect on casing. Casing is derived ONLY from the
  source string t. Even if context implies t is a button, menu item, heading,
  or label, casing STILL follows the source string's own casing and Dutch
  lowercase rules. Context never grants permission to apply title case.
  if the context (field c) contains 'short day name' or 'month name' then the word should be returned in lowercase
  Example: English 'Fri' -> Dutch 'vr'
  Example: English 'October' -> 'oktober'
